# GP AIスクール

株式会社GrowthPathが販売・サービス提供を行うオンラインAIスクールの販売サイトです。HTML・CSS・JavaScriptで構成しており、ビルドは不要です。

## 公開URL

https://nishita-gp1111.github.io/GP-LP/

## ローカルで表示

このディレクトリで次を実行し、http://127.0.0.1:8765/ を開いてください。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

`index.html` をブラウザーで直接開くこともできます。CSS・JavaScriptは同じディレクトリに置いてください。

## 制作状態

画面とプラン選択の動作を実装しています。販売条件が未確定のため、申込・決済は受け付けません。全ページは検索エンジンに登録しない設定です。公開先は GitHub Pages（`main` ブランチのルート）です。`main` への更新をプッシュすると、自動で公開版へ反映されます。

### 販売開始前に確定・接続する項目

- 運営統括責任者、問い合わせメール・電話番号または開示方針、受付時間、返信目安
- 支払時期、銀行振込の期限・振込先・手数料負担
- キャンセル・返金・中途解約の条件
- 継続プランの更新日、請求時期、解約手続き・締切・適用日・返金の扱い
- コンサル予約・日程変更・欠席、質問の対応範囲、特典ツールの利用条件
- 特商法表記・受講規約・プライバシーポリシーの確定
- UnivaPay決済の接続、支払完了後の受講案内・Discord招待
- 実際の講座画面等の素材（現段階は文章と学習フローで構成）

上記の確定前は販売開始・決済審査提出用の完成版ではありません。決済ボタンだけを有効にせず、販売条件の整合と決済連携を確認してください。

## 商品情報の編集

申込画面のプラン情報は `plans.js`、切り替え動作は `apply.js`、トップのサービス説明切り替えは `features.js` と `main.js`、共通デザインは `styles.css` にあります。料金等を変更する場合はトップ、申込、特商法表記、受講規約の各表示も合わせて更新してください。
